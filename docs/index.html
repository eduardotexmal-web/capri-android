¿Qué puede hacer Capri?

No es solamente una aplicación de chat. Capri está diseñada para acompañarte mientras utilizas tu teléfono.

Siempre contigo

Puede aparecer encima de tus aplicaciones y moverse por la pantalla.

Tu música

Interactúa con la música que estás reproduciendo y ofrece controles multimedia.

Inteligencia artificial

Permite conversar con proveedores de IA compatibles y configurar tu conexión.

Personalidad propia

Animaciones, expresiones, sonidos, idiomas, recordatorios y otras interacciones.

Requisitos

Android

Android 8.0 (Oreo) o superior. API 26 como versión mínima.

Internet

Necesario para descargar la aplicación, recibir actualizaciones y utilizar servicios de IA en línea.

Permisos

Permitir mostrarse sobre otras aplicaciones. Las notificaciones y el micrófono dependen de las funciones que actives.

Almacenamiento

Espacio disponible para instalar el APK y almacenar los datos de la aplicación.

El rendimiento puede variar según el teléfono, su memoria y la versión de Android. Cumplir el requisito mínimo no garantiza que todas las funciones estén disponibles en todos los dispositivos.

Instalación

  1. Pulsa el botón de descarga para abrir la última versión publicada en GitHub.
  2. Descarga el archivo APK correspondiente.
  3. Abre el archivo y autoriza la instalación desde esa fuente si Android lo solicita.
  4. Abre Capri y concede los permisos de las funciones que quieras utilizar.
  5. ¡Listo! Ya puedes iniciar Capri.

Las actualizaciones también se publican en GitHub Releases. Capri puede avisarte cuando haya una nueva versión.
